# Core has a registered @opencode-ai/core#test Turbo task and is also selected for fast coverage.
# Fast mode groups exact selected files by package and runs one owning Turbo test task with those file arguments;
# packages without a task use their package test script. Turbo supplies strict env, package-local config, and declared
# preparation. Bun's package lifecycle is preserved: pretest failure stops test/posttest, and test failure skips
# posttest; hook failures still propagate. Fast mode traverses commandless Turbo nodes, but refuses test-running or
# non-build prerequisites outside JUnit validation. JUnit from selected tests, preparation tasks, and lifecycle hooks
# is collected together, and the observed executed-file set must exactly equal this manifest for PATH-resolved Bun
# test launches (swxtchio/swx-opencode#324). Linux procfs/ptrace with Python 3 observes child execs: unobserved Bun tests and Node
# --test launches invalidate the run; bun run --bun is refused. A package-local turbo.json without a resolved test task
# is refused. This speedup is not a security boundary; see tests/run.sh for residual observation limits.
# The observer captures the loaded interpreter identity and kernel-expanded argv at exec stops, before user code runs;
# incomplete observation is refused. Later script replacement or cwd cleanup cannot substitute audit-time filesystem state.
# Changes touching an excluded timing class require that class at the final gate via
# firstmate's repository suite override; release builds require a passing full suite.
